# Radar Docs

This folder keeps Radar backend documentation that was previously stored at repository root.

- `RADAR_SERVICE_IMPLEMENTATION_LOG.md`: implementation progress log and recent work completion notes.
- `RADAR_SERVICE_SPLIT_PRD.md`: migration and service split plan for Radar ownership.
- `RADAR_IMPLEMENTATION_MATRIX.md`: implemented vs planned radar capabilities.
- `RADAR_DB_OPERATIONS.md`: DB schema, table ownership, and operations runbook notes.
- `RADAR_SUMMARY_PIPELINE_PRD.md`: summary pipeline design and reliability requirements.
