# Breaking Draft Workflow

Use this skill for newsroom-grade draft preparation from breaking signals to publish-ready channel variants.

## Workflow

1. Evaluate breaking candidate.
- Confirm recency, source trust, and cross-source confirmation.
- Reject low-confidence or stale candidates early.

2. Build draft from structured facts.
- Keep claims grounded in available source metadata.
- Preserve source links and publication context.
- Avoid unsupported speculation.

3. Run editorial checks.
- Verify factual consistency and timeline clarity.
- Ensure Spanish phrasing is concise and neutral.
- Mark uncertainty explicitly when evidence is partial.

4. Adapt for distribution.
- Produce channel-specific variants (short-form/social/newsletter).
- Preserve core facts across versions.

5. Report.
- `Findings`
- `Draft Decisions`
- `Validation`
- `Rollback/Revision Plan`
